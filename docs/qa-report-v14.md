## 3. 逐靶点结论

### 靶点 1 — 算例 A/B 独立重算 ✅ 通过
见 §2：A = **17000 / 17000**（差 0）；B = **14400 / 2400**（差 12000 = F）。

### 靶点 2 — JSON 类型 ✅ 通过
真实 `GET /api/stats/dashboard`：`annualTotalPremium` 与 `unpaidAnnualPremium` 均为 **`float`**（非字符串）；原始 JSON 文本中 `"annualTotalPremium":"` / `"unpaidAnnualPremium":"` **均不存在**（未被序列化为字符串）。

### 靶点 3 — 边界攻击（自构造用例）✅ 全部通过

| 场景 | 应缴 | 未缴 | 结论 |
|---|---|---|---|
| 生效中 + 未缴清 | 1000 | 1000 | ✅ 两口径都进 |
| **生效中 但 is_paid_off=True** | 1000 | **0** | ✅ **核心差异点正确**（先断言该单确实 `status=生效中 & isPaidOff=True`） |
| 已缴清 + 非趸交（12000） | 12000 | 0 | ✅ 只进应缴 |
| 已退保（5000）/ 已失效（7000） | 0 | 0 | ✅ 两口径都不进 |
| 趸交已缴清（50000） | 0 | 0 | ✅ 年化 0，两口径贡献均 0 |

### 靶点 4 — 两条不变式 ✅ 通过
混合集合（A生效中未缴清1000 / B生效中已缴完2000 / C已缴清3000 / D已退保9000 / E趸交已缴清50000）：
- **①** `annualTotalPremium − unpaidAnnualPremium` = 6000 − 1000 = **5000** == 已缴部分（B 2000 + C 3000 + E 0）✅
- **②** `Σ byMember.byInsured.annualPremium` = **1000** == `unpaidAnnualPremium`（**且 ≠ annualTotalPremium**）✅
- 示例数据上 ② 亦成立：`Σ byInsured = 4000 == unpaidAnnualPremium` ✅

### 靶点 5 — 未改坏其它维度 ✅ 通过
算例 A：`byMember.byInsured` 张三 (2, 6000, 81500) / 李四 (1, 8000, 32000) / 小张 (1, 3000, 3000)；`byType` 医疗8000→重疾6000→意外3000；`byPolicyholder` m1 (4, 17000)；`upcoming60Premium=4000` / `Count=3`。算例 B：张三 (2, 2400, 50000) / 王五 (1, 0, 60000)；`upcoming=0/0`。**均与 v1.3 逐值一致**。
